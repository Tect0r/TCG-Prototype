## Correction Tranche D — Operational safety and final closure

### M08.R11 — Exclusive orchestrator lock

The reviewed lock acquisition performed a read followed by atomic replacement. Two processes can both observe no lock and both succeed.

Implement genuinely exclusive acquisition using an atomic create (`wx` or equivalent) or an atomic lock-directory design. Stale-lock takeover must itself be serialized; two contenders must not both replace a stale owner. Release must only remove the lock still owned by that process.

Tests must prove:

- two concurrent acquisitions yield exactly one winner;
- the loser receives the documented busy/ownership refusal;
- a valid owner can release and another process can then acquire;
- stale takeover yields exactly one winner under contention;
- an old owner cannot release a newer owner’s lock;
- malformed lock data and clock/lease boundaries fail safely.

### M08.R12 — Symlink- and race-safe artifact reads

The reviewed artifact service validated the run directory but then performed `stat` and `readFile` on an individual artifact path. That follows a file symlink and separates size validation from the actual read, enabling escape or swap/growth races.

Open and validate the exact object that is read:

- reject symlink artifact files using `lstat`/no-follow open behavior available on the platform;
- verify the opened object resolves beneath the allowed root;
- `fstat` the opened descriptor;
- enforce the byte limit against that descriptor;
- perform the bounded read from the same descriptor;
- reject non-regular files;
- keep errors sanitized and path-free at the client boundary.

Tests must include:

- artifact file symlink to a file outside the root;
- symlink chain and dangling symlink;
- artifact swapped between validation and read;
- file growth across the size boundary;
- directory traversal and encoded traversal identifiers;
- ordinary allowed file, exact limit, and one byte over the limit.

Where a platform cannot guarantee the required no-follow behavior, refuse the unsafe operation rather than falling back silently.
